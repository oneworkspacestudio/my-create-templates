# Original starter collection

User authorized creation of My Create in the ecosystem, GitHub publication and
release. This separate repository contains only three newly authored CC0 designs
(social, invitation, flyer), no imported/private owner content or catalogue assets.
Packs use schema1, stable IDs, internal hashes, licence/author and offline previews.
Generated and round-trip checked by My Create scripts/export-starters.mjs; catalogue
records external SHA-256. Published main and v1.0.0. All 4 public assets (three packs and catalog) match
local SHA-256 and sizes. My Create1 and Workspace57 are released and installed.
GitHub Actions are disabled; no private content was published. Existing packs
and released assets are immutable.

Operational note: stale global Git safe-directory entries for unavailable drives
can stall Git when working on exFAT. Per-command GIT_CONFIG_GLOBAL=NUL and
GIT_CONFIG_NOSYSTEM=1 with this exact safe.directory and explicit author identity
worked; no global configuration was changed. Task-owned blocked diagnostic
processes received termination requests; some Windows I/O waits did not exit.
These are separate from the stopped synthetic app services.
